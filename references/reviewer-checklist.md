## A. 数据与泄漏（最容易被打死的一类）

| # | 审稿人可能说 | 你该交出的证据 | 错误答法 |
|---|---|---|---|
| A1 | 随机划分导致同一样品的另一次测量进了训练集 | 分组 CV（GroupKFold by sample_id）+ 每折样品数 | "我们用 5 折交叉验证"（没提分组） |
| A2 | 你怎么确认没有泄漏？ | `selfcheck` 的泄漏探针结果：随机 KFold R²=0.98 vs 分组 R²=-1.16 | 只口头保证 |
| A3 | n=180 还是 n=60？ | 明确写"60 个独立样品、180 条光谱" | 只写 180 |
| A4 | 预处理是在全量数据上做的吗？ | 说明 MSC 参考谱/标准化参数只在训练折估计；`selfcheck` 有对应断言 | "预处理不影响结果" |
| A5 | 特征筛选和评估用了同一份数据？ | 说明本流程不做独立特征筛选（用正则化代替） | 先选波段再报同一份 CV |
| A6 | 目标列有没有参与特征？ | 审计的"疑似目标泄漏"一项（单特征 \|Spearman\|>0.98） | 不检查 |
| A7 | 序号/编号列是不是当特征用了？ | 审计的"疑似把 ID 当特征" | 不检查 |
| A8 | 标签编码对吗？ | `task.label_order` 显式指定，报告里写阳性类 | 让字母序决定阳性类 |
| A9 | 是不是把同一批次的样品分到了训练和测试？ | 批次分布表；需要时用 `loo_batch` | 不提批次 |
| A10 | 异常值怎么处理的？ | 说明未剔除（或说明剔除规则），并用 AD 标出离群 | 悄悄删掉再看结果 |

## B. 交叉验证与调参

| # | 审稿人可能说 | 你该交出的证据 | 错误答法 |
|---|---|---|---|
| B1 | R² 是调参调出来的？ | 嵌套 CV：内层选参、外层评估 | "我们用了网格搜索" |
| B2 | 换个划分结果会变吗？ | 重复 CV 的 mean±sd + F3 | 只报一次 5 折 |
| B3 | sd 怎么算的？ | 先按 repeat 求折均值再求 sd | 把 R×k 折混算（sd 被低估） |
| B4 | 为什么 5 折不是 10 折？ | 独立样品数与折内样品数说明 | "10 折更好"（无依据） |
| B5 | 小样本下折内只有几个样品？ | 逐折 `n_test`（T3） | 不给 |
| B6 | 内层也分组了吗？ | 是，显式 split 列表 | "内层用普通 K 折"（会泄漏） |
| B7 | 超参搜索空间多大？ | `cv/fold_results.csv` 的 `best_params` + 候选数 | 只给最终值 |
| B8 | 不同折选出的超参差别大吗？ | T3 的 `best_params` 列 | 只报一个"最优超参" |
| B9 | 有没有用测试集选模型？ | 说明模型选择也在内层；比较用配对 bootstrap | "我们挑了最好的那个" |

## C. 性能与不确定度

| # | 审稿人可能说 | 你该交出的证据 | 错误答法 |
|---|---|---|---|
| C1 | 指标没有置信区间 | cluster bootstrap CI（`metrics_ci.csv`） | 只给点估计 |
| C2 | 为什么用 R² 不用 RMSE？ | 两者都报；说明 R² 依赖 y 方差、不可跨数据集比 | 只报 R² |
| C3 | RPD 多少？ | T2 的 RPD（+RPIQ），并说明样本范围 | 不报 |
| C4 | 有没有系统偏差？ | Bias + pred~obs 斜率 + Bland-Altman（F5） | 忽略 |
| C5 | 斜率 0.96 算不算偏差？ | 结合 CI 与偏离幅度说明"统计显著但实际影响小" | 看到 p<0.05 就说"有严重偏差" |
| C6 | 两个模型差异显著吗？ | 配对 bootstrap ΔCI + BH 校正（T4） | 比较两个 R² 谁大 |
| C7 | 多重比较校正了吗？ | T4 的 `p_BH`、`p_bonf` + 家族大小 m | 只报原始 p |
| C8 | 为什么不用 DeLong 检验？ | 说明分组数据下 DeLong 的独立性假设不成立，以配对 bootstrap 为主 | 硬用 DeLong |
| C9 | 分类为什么只看 accuracy？ | 平衡准确率、MCC、AUPRC、灵敏度/特异度两套阈值 | 只看 accuracy |
| C10 | 概率校准了吗？ | F5 校准曲线 + Brier + Brier Skill | "AUC 高所以概率可信" |
| C11 | 阈值怎么定的？ | 内层 CV 的 Youden 点，固定后用于外层 | 在测试集上调阈值 |
| C12 | 训练集和测试集性能差多少？ | T3 的 `r2_train` vs `r2`（过拟合幅度） | 不报训练性能 |
| C13 | 你凭什么说这个模型"最优"？ | 与次优模型的配对 bootstrap 差值 CI + `p_BH`；CI 跨 0 时改写成"性能相当" | 按均值和排名宣布最优 |

## D. 过拟合与"是不是在拟合噪声"

| # | 审稿人可能说 | 你该交出的证据 | 错误答法 |
|---|---|---|---|
| D1 | 怎么证明不是拟合噪声？ | Y-randomization 零分布 + p（`perm/permutation.json`、F6） | "R² 很高所以不是" |
| D2 | 置换是按行还是按样品？ | 按样品，分组结构不变 | 按行置换（零分布偏移） |
| D3 | 置换时重调参了吗？ | `mode` 字段：fast=固定超参（保守），full=重调 | 不说清 |
| D4 | 零分布均值为什么是正的？ | 说明这说明流程有泄漏，需排查 | 解释成"模型强" |
| D5 | p=0.05 够吗？ | n_perm 与最小可达 p（1/(n_perm+1)）一起报 | 报 p=0.000 |
| D6 | 样本量够建模吗？ | n/p、n/√p、EPV（audit.md） | 不评估 |
| D7 | 为什么不用更简单的模型？ | PLS 基线结果并列（T2） | 只报 GBDT |

## E. 适用域与外推

| # | 审稿人可能说 | 你该交出的证据 | 错误答法 |

## 怎么用这份清单

1. 出完报告后，先读自动生成的 `report/reviewer_checklist.md`（带 ✓/⚠）；
2. 对每个 ⚠，决定是"补做分析"还是"写进 limitations"——**不要删掉相关分析**；
3. 投稿前，用 A1、B1、C1、D1、E1、G1 这六条做最后自查，它们是命中率最高的。
