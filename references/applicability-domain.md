# 适用域（Applicability Domain）

AD 回答一个很实际的问题：**这个新样品，模型敢不敢用？**

审稿人版的说法是："你的模型在什么范围内有效？给出证据。"

---

## 1. 四种方法，各有盲区

| 方法 | 统计量 | 捕捉什么 | 盲区 |
|---|---|---|---|
| Hotelling T² | `Σ t_i²/λ_i`（PCA 得分空间马氏距离） | 在已有变化方向上走得过远 | 对"全新方向"不敏感 |
| Q 残差（SPE） | `‖x - x̂‖²` | 出现了训练集没有的变化方向 | 对幅值变化不敏感 |
| kNN 距离 | 到第 k 近邻的欧氏距离 | 局部密度稀疏区 | 高维下距离集中，阈值失效 |
| Leverage（Williams） | `h_i = t_iᵀ(TᵀT)⁻¹t_i (+1/n)` | 对模型拟合的影响力 | 只反映 X 空间，与 y 无关 |

**T² 与 Q 是一对**：只做 T² 会漏掉全新谱形（新杂质峰），只做 Q 会漏掉极端值。
**kNN 必须在降维后的空间算**：2000 维原始光谱上所有点几乎等距（距离集中现象），
阈值毫无意义。

本技能四种都算，输出 `ad_votes`（0–4）与两种合并判定：
* `ad_flag`：任一越界即域外（保守，推荐）
* `ad_majority`：多数票越界（宽松）

---

## 2. 阈值怎么定

### 2.1 T² 的理论阈值

```
T²_crit = p(n-1)(n+1) / (n(n-p)) · F(1-α, p, n-p)
```

其中 p = 主成分数，n = 训练样本数。

**小样本下 F 近似偏乐观**（n/p < 10 时尤其明显）。所以本技能默认取训练集
**经验 95% 分位**作为阈值，并在 `ad_eval.json` 里同时保留 F 理论值供对照。

### 2.2 Q 残差

理论上是 χ² 分布，但它假设残差独立同分布，实际光谱残差强烈相关。**一律用经验分位。**

### 2.3 Leverage

Williams 惯例：`h* = 3(p+1)/n`（p 为模型参数个数即主成分数）。
本技能取 `max(3(p+1)/n, 经验 95% 分位)`。

### 2.4 分位数的选择

95% ⇒ 训练集里约 5% 会被判为域外（假阳性率可预期）。
若样本很少（n<30），95% 分位本身估计不稳，可放宽到 99%，或干脆只做描述不做判定。

## 3. 必须验证 AD 的有效性

**"我们做了适用域"不是结论。** 真正的结论是：

> 域外样本的预测误差显著大于域内样本。

检验方法：把 OOF 的绝对残差按 `ad_flag` 分组，做单侧 Mann-Whitney U（域外 > 域内）。

| 结果 | 该怎么写 |
|---|---|
| p<0.05 且域外误差更大 | ✓ 适用域有效，新样品预测前先判域 |
| p≥0.05 | ⚠ 当前 AD 无法识别不可靠预测 → 写进 limitations，**不要宣称可外推** |

本技能会自动判定并写进报告的 limitations。**这是刻意设计的"如实报告"行为**——
很多论文在这里含糊过去，反而是最容易被抓的地方。

### 3.1 口径：只能报独立样品数

`ad_flag` 是**逐行**判的（一行 = 一次测量），而 OOF 里同一样品会出现
「重复测量数 × 重复次数」次。本项目 60 个样品 × 3 次测量 × 2 次重复 = 360 行，
直接报行数会把域外样品数放大 6 倍，是审稿人一算就能发现的硬伤。

| 口径 | 字段 | 用途 |
|---|---|---|
| 独立样品（**论文用**） | `n_outside_groups` / `n_groups` | "8 / 60 个样品（13.3%）" |
| OOF 行（仅备查） | `n_outside` / `n_oof_rows` | 追溯逐行标记，不进正文 |

样品级判定规则：**样品内任一测量被判越界，即该样品计为域外**（保守口径，
`group_rule` 字段里写明）。同时给出多数测量口径 `n_outside_groups_majority`，
两者差异大说明该样品处在域边界上，值得单独讨论。

`ad_eval.json` 的 `conclusion` 是**论文可直接引用**的句子；`author_note`
是写给作者的写作指引（"不得宣称…""必须写入 limitations…"），
只会出现在报告的"写作提示"块与审稿清单里，不会进正文。

## 4. 新样品怎么用

```python
import joblib, numpy as np, pandas as pd
ad = joblib.load("runs/nir_v1/ad/ad_model.joblib")
X_new = ...                       # (m, n_features)，列顺序必须与训练时一致
scores = ad.score(X_new)
print(scores[["ad_votes", "ad_flag", "t2", "q", "knn_dist", "leverage"]])

inside = scores["ad_flag"] == 0
# 只对域内样品给出正式预测；域外的给出预测但标注"外推，可信度低"
```

**列顺序**：`config.resolved.json` + `cv/models.json` 记录了特征名，
务必按 `feature_names` 的顺序组织新数据（本技能在读数据时保持表头顺序）。

## 5. 常见错误

| 错误 | 后果 |
|---|---|
| 在原始高维空间算 kNN 距离 | 距离集中，阈值失效，全部判域内 |
| 用 y 参与 AD 拟合 | 变成监督信息，失去"仅凭 X 判是否可信"的意义 |
| 只在训练集上报告 AD 覆盖率 | 训练集覆盖率天然是 95%（因为阈值来自它），无信息量 |
| 域外样本直接剔除后再报性能 | 这是选择性报告；正确做法是报告"域内/域外两套性能" |
| 用 AD 替代外部验证 | AD 只说明"像不像训练集"，不说明"预测准不准" |

## 6. 与批次效应的关系

跨批次外推失败时，AD 通常是第一个报警的：新批次的整体谱形因散射/基线不同而
在 PCA 空间偏出一侧 → T² 高。

因此一个实用流程是：

1. `--set split.strategy=loo_batch` 看跨批次性能；
2. 看 `ad/ad_scores.csv` 里留出批次的 T²/Q 分布；
3. 若留出批次系统性越界 → 结论应是"需要批次校正（如 PDS/DS 迁移）后再用"，
   而不是"模型效果不好"。
