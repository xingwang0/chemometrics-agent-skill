# 光谱预处理：算子、顺序与参数

本技能把预处理实现为一个**候选链列表**（`preprocess.candidates`），每条链是一个离散超参，
由内层交叉验证选出。这样"预处理是挑过的"这一质疑被方法学消掉。

---

## 1. 推荐顺序

```
波段裁剪 → 基线校正 → SG 平滑（可选）→ SG 求导 → SNV / MSC → （标准化）
```

理由：
* **先基线后归一化**：基线是加性漂移，归一化是乘性缩放。先除基线再缩放才物理上有意义。
* **求导前先平滑**：一阶/二阶导数把高频噪声放大 √2 倍/更多，不平滑会得到锯齿。
  若用 SG 且 `deriv>0`，SG 本身带多项式平滑，无需额外平滑步骤。
* **MSC 放在最后**：MSC 假设乘性散射，与导数交换性差；先求导再做 MSC 会引入伪影。
* **SNV 与 MSC 二选一**：两者都是散射校正，叠加使用没有额外收益（SNV 是 MSC 的逐行版本）。

---

## 2. 算子清单

### 2.1 SNV（标准正态变量变换）

```
x' = (x - mean(x)) / std(x)     逐行
```

* 无参数，无 fit 需求，最安全的第一选择
* 消除光程差异、粉末粒度导致的乘性散射
* **不适用于**：只有少数几个峰的稀疏谱（会把噪声归一化成信号）

```json
{"op": "snv"}
```

### 2.2 MSC（多元散射校正）

```
以参考谱 r（默认取训练折均值谱）做 OLS：x = a·r + b
x' = (x - b) / a
```

* **有状态**：参考谱必须只在训练折内估计（本技能已保证）
* 相比 SNV 保留了"与平均谱形状差异"的信息，通常略优
* 参数：无（参考谱自动算）

```json
{"op": "msc"}
```

> 泄漏提醒：手工做 MSC 时若用全量数据的均值谱，R² 会虚高。
> `selfcheck` 的"预处理只在训练折内 fit"一项就是查这个。

### 2.3 Savitzky-Golay（平滑 / 求导）

```
多项式最小二乘拟合滑窗，取中心点的拟合值（deriv=0）或导数（deriv≥1）
```

| 参数 | 含义 | 推荐 |
|---|---|---|
| `window` | 窗口点数，**必须奇数** | 11–21（点数越多越平滑） |
| `polyorder` | 多项式阶数，必须 < window | 2（标准）；1 更保守 |
| `deriv` | 0=平滑, 1=一阶导, 2=二阶导 | 1 最常用 |
| `delta` | 波长间隔（求导时用于缩放） | 若波数间隔 4 cm⁻¹ 则填 4 |

```json
{"op": "sg", "window": 11, "polyorder": 2, "deriv": 1, "delta": 4}
```

**已知坑**：scipy 1.18 起 `savgol_filter` **静默接受偶数窗口**（旧版报错）。
偶数窗口的 SG 中心点定义不唯一，会得到非标准结果。本技能在配置校验阶段直接拦截
（`E-CFG-023`），不允许偶数。

**导数放大噪声**：二阶导的噪声放大约 √6 倍。若二阶导后 R² 骤降，先把 window 加大。

### 2.4 airPLS 基线校正

自适应迭代重加权惩罚最小二乘（Zhang et al., 2010）。对每个谱求一条平滑"下包络"作为基线：

```
min_z  Σ w_i (y_i - z_i)² + λ Σ (Δ²z)²
w_i 迭代更新：残差为负（在基线上方）的点权重小，为正的点权重大
```

| 参数 | 含义 | 推荐 |
|---|---|---|
| `lam` | 平滑强度，越大基线越平 | 1e4–1e7（谱越长越大） |
| `order` | 差分阶数 | 2 |
| `max_iter` | 迭代上限 | 20 |

```json
{"op": "airpls", "lam": 100000.0, "order": 2, "max_iter": 20}
```

比多项式基线更适应弯曲的荧光背景，比滚球法更平滑。**计算成本较高**（逐行稀疏求解），
2000 点 × 500 行约 3–5 秒。

### 2.5 多项式基线

```json
{"op": "baseline_poly", "order": 3}
```

快、可解释，适合基线形状规则的场合。缺点是要人工定阶数。

### 2.6 波段裁剪

```json
{"op": "band", "from_index": 0, "to_index": 600}
```

* 用**列下标**（不是波数），因为配置阶段还没读数据
* 用途：去掉饱和区、仪器死区、与目标无关的强吸收带
* **注意**：裁剪范围也是"人工选择"，若想彻底规避质疑，把它放进候选链列表里让 CV 选

### 2.7 归一化 / 差分

```json
{"op": "normalize", "mode": "l2"}     // l2 | max | area
{"op": "diff", "n": 1}                 // 简单差分，不如 SG 求导
```

## 3. 候选链怎么设

**数量控制在 3–5 条**。每条链增加 K 倍的搜索成本；超过 5 条时
`E-CFG-021` 会警告。

一个覆盖主流做法的四链配置：

```json
"candidates": [
  {"name": "raw",           "steps": []},
  {"name": "snv",           "steps": [{"op": "snv"}]},
  {"name": "sg1_snv",       "steps": [{"op": "sg", "window": 11, "polyorder": 2, "deriv": 1}, {"op": "snv"}]},
  {"name": "airpls_sg1_snv","steps": [{"op": "airpls", "lam": 100000.0}, {"op": "sg", "window": 15, "polyorder": 2, "deriv": 1}, {"op": "snv"}]}
]
```

选完之后，`cv/fold_results.csv` 的 `prep` 列会告诉你内层折选了哪条链——
如果不同折选得五花八门，说明预处理对结果影响不大（这本身是个可报告的结论）。

## 4. 常见错误

| 错误 | 后果 | 本技能的防线 |
|---|---|---|
| 用全量数据算 MSC 参考谱 | R² 虚高 | Transformer 只在训练折 fit；selfcheck 断言 |
| 用全量数据选波段/定 SG 参数 | R² 虚高 | 候选链进内层搜索 |
| SG 用偶数窗口 | 静默产出非标准结果 | 配置校验直接拒绝 |
| 先 MSC 后求导 | 伪影，峰位偏移 | 文档规定顺序；默认模板按此写 |
| 二阶导 + 小窗口 | 噪声爆炸，模型学噪声 | 建议 window ≥ 15（经验） |
| 归一化后再做峰值定量 | 把浓度信息也归一化掉了 | 光谱建模用 SNV/MSC，不要用 `l2` 归一化 |
