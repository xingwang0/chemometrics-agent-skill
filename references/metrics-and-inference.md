# 指标与统计推断

---

## 1. 回归指标

| 指标 | 公式 | 方向 | 什么时候看它 |
|---|---|---|---|
| R² | `1 - SS_res/SS_tot` | 越大越好 | 常规报告；但跨数据集不可比（依赖 y 的方差） |
| RMSE | `sqrt(mean((y-ŷ)²))` | 越小越好 | **主指标**，与 y 同单位，可解释 |
| MAE | `mean(|y-ŷ|)` | 越小越好 | 有离群点时比 RMSE 稳健 |
| Bias (ME) | `mean(ŷ-y)` | 接近 0 | 系统性高/低估；论文里非常值得单独报 |
| RPD | `SD(y)/RMSE` | 越大越好 | 化学计量学的"可用性"惯例 |
| RPIQ | `IQR(y)/RMSE` | 越大越好 | y 分布偏斜时比 RPD 可靠 |
| CCC | `2ρ·σ_y·σ_ŷ/(σ_y²+σ_ŷ²+(μ_y-μ_ŷ)²)` | 越大越好 | 同时惩罚"不相关"与"不一致" |
| slope | `Cov(y,ŷ)/Var(y)`（ŷ~y 回归） | ≈1 | 揭示范围压缩（<1）或外推放大（>1） |

**RPD 的分档（Williams）**：

| RPD | 用途 |
|---|---|
| > 3.0 | 可定量筛查 |
| 2.0–3.0 | 粗略定量 |
| 1.5–2.0 | 只能区分高/低 |
| < 1.5 | 不可用 |

RPD 依赖 y 的方差：如果把样本范围人为扩大（例如混入极端样品），RPD 会虚高。
**所以 RPD 必须与 RMSE 一起报，且说明样本范围。**

## 2. 分类指标

| 指标 | 说明 |
|---|---|
| AUROC | 排序能力，阈值无关。类别不平衡时不如 AUPRC |
| AUPRC | 阳性少时更敏感（推荐与 AUROC 并列） |
| 平衡准确率 | (灵敏度+特异度)/2，对不平衡稳健 |
| F1(macro) | 各类 F1 的宏平均 |
| MCC | 单值综合指标，类别极不平衡时仍可靠 |
| 敏感度/特异度 | 管线内统一按**阈值 0.5** 报；Youden 最优点未实现（见下） |
| Brier | `mean((p-y)²)`，越小越好，同时反映分辨力与校准 |
| Brier Skill | `1 - Brier/Brier_基准率`，>0 才算优于"全猜基准率" |
| ECE | 期望校准误差，分箱后 |观测率-预测率| 的加权和 |

**阈值不能在后测数据上调。** 如果要用 Youden 阈值，它只能在内层 CV 上选，
外层测试折一律用固定阈值，否则又是一个泄漏口。

**当前实现：管线一律用 0.5。** `metrics._youden_threshold()` 只是留给扩展用的
工具函数，**没有任何调用点**（`classification_metrics(threshold=...)` 也无人传值），
因此 `fold_results.csv` 与报告里的敏感度/特异度都是 0.5 阈值下的值。
论文里若要写"Youden 最优点并报"，必须自己改 `cv.py`（用训练折概率算阈值、随折落盘），
不要直接引用本管线——它没做这件事。

### 2.1 概率类指标的前提：`proba_kind` 三态

Brier / ECE / log-loss 的分母语义是「概率」。不是所有分类器都给概率：

| `proba_kind` | 来源 | 可用指标 |
|---|---|---|
| `native` | 原生 `predict_proba` | 全部 |
| `decision` | 只有 `decision_function`，经 sigmoid 单调映射 | AUC/AP/平衡准确率/MCC/灵敏度/特异度；**Brier/ECE/log-loss = NaN** |
| `none` | 只有 `predict`（硬标签） | 分类指标（AUC 退化为 (Se+Sp)/2） |

单调映射不改变排序，所以 AUC/AP 在 `decision` 下仍然有效；但 sigmoid 之后的数值
不是校准过的概率，拿去算 Brier 会得到一个"看起来合理"的错数。技能选择报 `NaN` 并在
报告 limitations 里写明，而不是给一个会被审稿人追问的假 Brier。

`fold_results.csv` 与 `oof_predictions.csv` 都带 `proba_kind` 列，可追溯每个模型走的哪条路。

## 3. 置信区间：cluster bootstrap

**按样本（group）重采样，不是按行。**

```
for b in 1..B:
    抽 n_groups 个样品（有放回）
    把这些样品的所有测量行一起带进重采样集
    在该集合上算指标 → 得到 B 个值
取 2.5% / 97.5% 分位
```

按行重采样会把"同一测量重复出现"当成独立信息，CI 系统性地偏窄。本技能在
`metrics.bootstrap_regression` 里硬性要求传入 groups，缺了直接报错。

**为什么快**：回归指标只依赖每组的充分统计量
`(n, Σy, Σy², Σŷ, Σŷ², Σyŷ, Σ(y-ŷ)², Σ|y-ŷ|)`，
重采样时按组权重累加即可，B=2000 在 n=2000 时约 0.1 秒（比逐次重算快 1–2 个数量级）。

分类指标无法用充分统计量（AUC 依赖排序），因此直接重算，B 建议 ≤1000。

## 4. 模型比较

### 4.1 配对 bootstrap（主）

同一批 OOF 样本上：

```
Δ = metric_A - metric_B（逐次重采样，两个模型用同一批样品）
CI 是否跨 0 → 差异是否显著
```

配对是必须的：两个模型面对的是同一批"难样品"，不配对会把样品难度差异算进模型差异。

### 4.2 Wilcoxon 符号秩（辅）

按 repeat 配对（n = repeats）。R 很小时（如 5）检验效能低，**只报 p 与效应量，不据此下结论**。

### 4.3 DeLong（仅参考）

DeLong 检验假设样本独立。**分组数据下这个假设不成立**，所以本技能以配对 bootstrap 为主，
不把 DeLong 当结论依据。

---

## 5. 多重比较

一次比较 6 个模型 → 15 个模型对 × 4 个指标 = 60 个检验。此时 p<0.05 出现 3 次的概率
约 85%，纯属偶然。

| 方法 | 做法 | 适用 |
|---|---|---|
| Bonferroni | `p × m` | 最保守，检验数少时用 |
| BH (FDR) | 排序后 `p_(i) × m / i` 取累积最小 | 检验数多时的常规选择 |

本技能三列并列输出 `p_raw / p_BH / p_bonf`，并在表脚注写清家族大小 m。
**只报原始 p 是审稿人最常抓的统计错误。**

### 5.1 "最优模型"必须先过显著性门槛

在 6 个模型里挑 `r2_mean` 最大的那个，即使每个都跑了嵌套 CV，**选完再报**仍然带
winner's curse：被选中的模型恰好是"在这批折上运气最好"的概率不低。

因此报告生成前会做一道门槛（`selection.significance_vs_runner_up`）：
取该模型与**同目标**次优模型的配对 bootstrap 差值（BH 校正），

* CI 不跨 0 → 写"X 显著优于 Y"，给出差值、CI、p_BH；
* CI 跨 0 → 写"X 与 Y 性能相当"，并把这条写进 limitations 与审稿清单；
* 缺对比行 → 明确写"未做显著性检验（原因）"，禁止宣称优于任何模型。

**阈值不能用来挑模型。** 同理，不要先按测试集 AUC 挑阈值再报该阈值下的准确率。

## 6. Y-randomization

```
观测 R²_obs（真实 y）
for i in 1..n_perm:
    在样品级置换 y → 重跑整条流程 → R²_null_i
p = (1 + #{R²_null >= R²_obs}) / (1 + n_perm)
```

**必须在样品级置换**：同一样品的多次测量共享同一个 y，若按行置换会造出
"同一样品有不同 y"的数据，零分布整体偏移。

**两种模式**：

| 模式 | 做法 | 成本 | 说明 |
|---|---|---|---|
| `fast` | 固定外层折 + 固定最优超参，只重跑外层拟合 | n_perm × R × k | 保守；报告需注明"固定超参" |
| `full` | 每轮完整嵌套 CV | n_perm × 完整 CV | 最严格，n_perm 建议 ≤100 |

**解读**：p<0.05 说明模型性能超出随机水平；零分布的均值应接近 0（或负），
若零分布均值明显为正，说明流程本身有泄漏（例如预处理在 CV 外 fit）。

化学计量学还习惯报 "R²_intercept"（随机化回归线的截距），本技能在
`perm/permutation.json` 里给了 `null_q025/q975`，可直接画 Mann 图。

## 7. 报告时的最小集合

回归论文至少给：

```
R², RMSE, MAE, Bias, RPD（+ RPIQ 更好），各自 95% CI，
外加 预测-实测散点（1:1 线）、残差图、CV 分布图
```

分类论文至少给：

```
AUROC（+AUPRC）, 敏感度/特异度（阈值 0.5；Youden 需自行扩展，管线未实现）,
MCC 或平衡准确率, Brier, 校准曲线
```
