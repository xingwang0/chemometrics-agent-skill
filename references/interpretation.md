# 可解释性：在高维共线光谱上怎么做才不被反打

---

## 1. 为什么 SHAP 在这里不能当主图

相邻波长（如 4000 与 4004 cm⁻¹）的数值几乎相同。在树模型里，分裂点可以落在其中任意一列，
于是 SHAP 会把同一个峰的信息**随机分摊**到几列上，结果取决于随机种子。

后果：你得到的"最重要波长"是 4008 还是 4012，纯属偶然。审稿人只要问一句
"为什么是 4008 而不是 4004？这个波数对应什么振动？"——你就没法回答。

此外，共线条件下 Shapley 值的分解**在数学上不唯一**（不同 feature 顺序给出不同归因），
这是可证明的性质，不是实现问题。

**结论**：SHAP 可以放在补充材料里作方向性参考，图上必须加注限制，不能作为主结论。

## 2. 正确顺序

### 2.1 主结果：波段级置换重要性

```
对每个波段（band_size 个连续波长）：
    把该段的所有波长在测试折内同时打乱（行间置换）
    用训练好的模型重新预测
    计算 ΔMetric = Metric_原 - Metric_置换
重复 n_repeats 次取均值
```

为什么按段而不按单列：
* 单列置换时，模型立刻用相邻列补上信息 → Δ≈0，"重要波段"被稀释成噪声；
* 按段置换才对应真实的化学问题："这段谱区整体缺失会怎样"。

配置：`interp.band_size`（默认 25）。经验值：
* 光谱 2000 点 → band_size 25–50（约 50–100 cm⁻¹ 宽）
* 光谱 500 点 → band_size 10–20
* 普通表格（非光谱）→ band_size = 1

产物：`interp/importance.csv`（每段一行，含 `delta_mean`、`delta_sd`、`share`）
图：F7（柱状 + 平均谱底图，横轴对齐波数）

### 2.2 VIP（PLS 专属，化学计量学惯例）

```
VIP_j = sqrt( p · Σ_a SS_a · (w_ja / ‖w_a‖)² / Σ_a SS_a )
SS_a = q_a² · t_aᵀt_a
```

* VIP > 1 通常被认为"重要"（p 个变量平均 VIP = 1）
* 本技能用 bootstrap（按样品重采样 100 次）给出 VIP 的 2.5%/97.5% 分位
* `vip_q025 > 1` 才是**稳健的重要**

**前提条件（v1.1.1 起强制标注）**：VIP 是 PLS 权重的衍生物，只有在 PLS 本身有预测力时
才可解读。PLS 学不到东西时，VIP 排序依然"看起来很专业"，但那是噪声的投影——实测一例：
PLS 的 CV R²≈0.01，VIP 首位是 `W_content`，而置换重要性首位是 `P_content`，两个"最重要
特征"方向完全相反，不标来源模型的性能，读者只能二选一凭感觉。

因此 `vip.csv` 每行都带两列：

| 列 | 含义 |
|---|---|
| `pls_cv_r2` | 该 run 里 PLS 基线的 CV 主指标（口径跟随 `metric_basis`） |
| `vip_reliable` | `pls_cv_r2 >= 0.10` 才为 true；false 时 VIP **只能作对照，不能当结论** |

不可引用时报告与审稿清单会自动改成 ⚠ 并建议改用置换重要性 / SHAP。

产物：`interp/vip.csv`

### 2.3 跨折系数稳定性

对支持系数的模型（PLS/Ridge/ElasticNet），把每个折的系数拼起来：

* `sign_consistency = max(P(coef>0), P(coef<0))`
* 一致率 < 0.8 → 该特征的作用方向随折变化，**不能作为化学结论**

这直接回答审稿人"你选出的波段稳定吗"。

产物：`interp/coef_stability.csv`

### 2.4 SHAP（补充）

`shap: "auto"` 时只在树模型上算，且：
* 传 numpy 数组（传 DataFrame 会触发 pandas 3.0 dtype 告警）
* 特征数多时先聚合到波段或降维
* 失败时降级为 permutation，不中断主流程

## 3. 把重要性映射回化学

F7 已经做了对齐：柱状图 x 轴 = 波数，下方是平均谱。

**但本技能刻意不自动给出官能团归属。** 原因：

* 峰归属需要文献支持与仪器条件（分辨率、信噪比）；
* 近红外的合频带高度重叠，一个"重要波段"往往对应多个基团的叠加；
* 自动贴标签是越界推断，是审稿人最容易质疑的"过度解释"。

正确做法：拿 `importance.csv` 的前 N 段波数，自己去查文献，在文中写
"4900 cm⁻¹ 附近对应酰胺 N-H 合频（引用）"，而不是让脚本替你写。

## 4. 常见错误

| 错误 | 问题 |
|---|---|
| 把 SHAP beeswarm 作为主图 | 共线下归因不唯一，见上文 |
| 单波长 permutation importance | 相邻列补偿，重要性被稀释 |
| 重要性在训练集上算 | 过拟合模型会让噪声列也"重要"；本技能在 OOF 折内算 |
| 用重要性做特征选择后又报同一份 CV 性能 | 特征选择也是拟合的一部分，会造成乐观偏差 |
| 把"VIP>1 的波长"直接说成"特征峰" | VIP 是统计量，不等于化学归属 |
| 重要性图不标波数轴 | 化学读者无法核对，等于没给 |

## 5. 如果必须做特征选择

"先选波段再建模"本身合理（尤其 n 很小时），但要满足：

1. 特征选择在**每个训练折内部**做（本技能不提供这个，因为它极易出错）；
2. 报告时要说明选择过程，且性能必须来自独立评估；
3. 或者更稳妥：用 PLS/Ridge 的正则化自动压缩，不显式选波段。

本技能的选择是：**保留全部特征，用正则化 + 波段级解释**。这对光谱数据通常已足够，
且不存在"选完再评估"的偏差。
