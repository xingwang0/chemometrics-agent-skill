### 图与表的数字不是一个口径（同页必须注明）

| 来源 | 口径 | 例子 |
|---|---|---|
| 表 T2 `metrics_summary.csv` | 先按 repeat 求折均值，再跨 repeat 求 mean±sd | R² = 0.969 ± 0.003 |
| 图 F1/F2/F5 的统计注记 | **OOF 池化**：把全部折外预测拼在一起算一次 | R² = 0.971 |

两者都对，差异来自池化会给样品数多的折更高权重。图上的统计框已标注"（OOF 池化）"，
`FIGURE_INDEX` 的图注也写明，报告的"可用图"列表会自动带出——**但正文引用时仍要自己说明**，
否则同页出现 0.971 与 0.969 会被当成数据打架。

AD 相关数字另有一套口径：**只报独立样品数**（见 `applicability-domain.md` §3.1），
不要把 `ad_eval.json` 里的行数写进正文。

### "最优模型"必须过显著性门槛

报告不会只因为 `r2_mean` / `auc_mean` 最大就宣布"最优"。它会取该模型与**同目标**次优模型的
配对 bootstrap 差值（`cv/comparison.csv`，BH 校正后）：

| 结果 | 报告怎么写 | 论文怎么写 |
|---|---|---|
| CI 不跨 0，p_BH < 0.05 | "最优模型 X（显著优于次优 Y，p=…）" | 可以写"X 优于 Y" |
| CI 跨 0 | "X 与 Y 差异未达显著 → 性能相当" | 必须写"二者性能相当"，不能只推荐 X |
| 缺对比行 | "未做显著性检验（原因）" | 不要声称优于任何模型 |

不显著的结论会同时进入 limitations 与审稿清单——因为"在 12 个模型里挑最好的那个"
即便每个都跑了嵌套 CV，选完再报仍然带 winner's curse 的味道。

多目标时 T2 的 CI 必须按 **(target, model)** 对齐。只按 `model` 建字典会让后一个目标
覆盖前一个，两个目标显示同一组区间且不报错。多目标请用 `run_pipeline`（自动拆子 run）。

### 聚合口径（容易被问，也容易做错）

`cv/metrics_summary.csv` 按 **(target, model)** 聚合，另给 `prep_mix` 列
（如 `raw×14、snv×1`）。**不要**按"模型×预处理"拆成多行再排名：

* 预处理链是**逐折内部**由内层 CV 选出的超参，不是一个"模型配置"；
* 一旦按 `(model, prep)` 拆分，同一模型会被切成几行，各行的样品集合不同，
  排名就退化成"在几十个组合里挑最优"（winner's curse），而且看上去最好的那行
  往往只是一个碰巧有利的子集。

实测例子：某个分类模型在它选中 `raw` 的 6 折上 AUC=0.973（看似第一），
但另外 9 折它选了更差的预处理，按全部折聚合后 AUC 只有 0.870。
**报 0.973 是错的。**

需要细分时看 `cv/metrics_by_prep.csv`，并在正文里说明"这是按折内预处理选择事后拆分的结果，
不作为模型排名依据"。

**表 T2 的口径列**：`metric_basis`（`fold` / `pooled`）、`n_folds_ok`、
`n_folds_degenerate` 必须随 T2 一起保留。`pooled` 表示该行有效折不足 3 个
（留一法下必然如此），`*_mean` 只来自极少数折，**不可引用**；这些行在报告里标 `†`，
并并排给出 `r2 (池化)` / `rmse (池化)`。同一张表里 `fold` 与 `pooled` 混排时必须注明，
不能拿 `†` 行的 `r2_mean` 和别的行比较。

## Methods 段落必备要素（自查清单）

一段合格的 Methods 至少要让读者能独立复现：

- [ ] 样本量与**独立样品数**（不是光谱条数）
- [ ] 光谱采集条件：仪器型号、波数范围、分辨率、扫描次数
- [ ] 预处理链（具体参数：窗口、阶数、导数阶、基线方法）
- [ ] 预处理参数是否在训练折内确定
- [ ] 分组键是什么（`sample_id`），为什么必须分组
- [ ] 外层折数 × 重复次数；内层折数
- [ ] 超参数搜索空间与搜索方式
- [ ] 使用了哪些模型，为什么包含 PLS 基线
- [ ] 主要指标及其定义（RPD/RPIQ 要写公式或引用）
- [ ] 不确定度方法（cluster bootstrap，B 次）
- [ ] 模型比较方法与多重比较校正
- [ ] Y-randomization：置换次数、样品级、是否固定超参
- [ ] 适用域方法、阈值来源、有效性验证方式
- [ ] 软件与版本、随机种子、数据/代码可获取性

`report/methods_zh.md` 与 `methods_en.md` 按这个清单生成，缺的字段会留占位符提示补全。

## 报告结构（`report/report.md`）

1. **结论摘要** —— 5–8 条，每条都能点回具体产物
2. **数据与任务** —— 规模、分组结构、批次、条件数/有效秩
3. **验证方案** —— 策略、折数、聚合口径
4. **性能结果** —— T2 表 + 图清单
5. **模型比较与不确定度** —— T4 + 家族大小说明
6. **是否在拟合噪声** —— F6 + p 值
7. **适用域** —— F4/T5 + 有效性结论
8. **可解释性** —— F7 + VIP + 系数稳定性 + 共线性告诫
9. **局限** —— 自动生成，含无批次/无重复/AD 无效等
10. **复现信息** —— 三哈希 + 版本 + 种子

## 出图时最容易踩的坑

| 坑 | 表现 | 处理 |
|---|---|---|
| 上标 Unicode 缺字 | `cm⁻¹` 变 `cm□1` | 用 mathtext `cm$^{-1}$` |
| 横轴用波段序号而非波数 | 化学读者无法核对 | F7 已按列名波数对齐 |
| 平均谱把成分列算进去 | 出现一个巨大的尖峰 | 只取"列名为数值"的列做平均谱 |
| 中文字体缺失 | 方块 | `selfcheck` 报字体名；装思源黑体 |
| 图太密 | 缩到单栏后看不清 | 单图单栏宽 3.4–4.8 in，不要塞满 |
| 用颜色区分 8 个模型 | 无法辨色 | 超过 5 类改用直接标注 + 分面 |
| 保存时 `bbox_inches` 未设 | 标签被裁 | 本包统一 `bbox_inches="tight"` |

## 展示规范（1.2.0 起，代码强制）

以上是"应该怎么做"，下面这些是"做不到就会失败"的部分。全部由 `sml/present.py` 的
字段规格驱动，Markdown、HTML、xlsx 显示格式与图内注记共用同一份定义。

### 精度

| 类别 | 字段 | 规则 |
|---|---|---|
| 有界无量纲 | R²、AUROC、AUPRC、平衡准确率、F1、MCC、CCC、灵敏度、特异度、准确率 | 3 位小数 |
| 可用性指数 | RPD、RPIQ | 2 位小数 |
| 有量纲误差量 | RMSE、MAE、bias、截距、Δ、阈值 | **4 位有效数字**（不是 4 位小数） |
| 计数 / 排名 | n、独立样品数、有效折数、rank | 整数，不带千分位（`1,024` 会被读成 1.024） |
| p 值 | p、p_BH、p_Bonf | `p<0.001` / `p>0.999` 用不等号，其余 3 位小数 |
| 比例 | 域外比例、失败折比例 | 百分数 + 1 位小数；CSV 里仍存 0–1 |

三条硬规则：

1. **零值只写 `0`**：`-0.0` 归一为 `0`，所以 `-0.000`、`0.0000` 结构上不会出现。
2. **禁止二次舍入**：`fmt_detail` 收到已格式化的 `Formatted` 直接 `TypeError`；
   差值必须由原始值算（`fmt_delta(a_raw, b_raw)`）。
3. **CSV / XLSX 存全精度**：只有"人看的字符串"和 xlsx 的 `num_format` 会舍入。
   不要在 `build_tables` 里 `df.round(3)`——那会断掉"所有数字可从
   `cv/oof_predictions.csv` 重算"的承诺，并让 `rebuild_tables.py` 在舍入值上重算 sd。

### 单位

- 目标单位来自 `data.target_unit`。缺失时**三处同时显式告警**：表头/轴标签写
  「单位未指定」、页面挂 blocking 徽标、`compliance.json` 记录一条。
- 三种载体写法互斥：Markdown 用 `cm^-1`、HTML 用 `cm<sup>−1</sup>`、
  matplotlib 用 `cm$^{-1}$`。混用就是"图内方块、网页正常"的成因，`unit_suffix` 会断言拦住。

### 状态徽标

`†` 池化口径 · `‡` 含退化折 · `⊘` 适用域无效 · `○` 域外样品 · `⇱` 预测值越界 ·
`≈` 概率非原生 · `=` 差异不显著 · `¹` 单次重复 · `–` 无 CI · `?` 单位未指定 ·
`×` 模型失败 · `!` 满分指标 · `b` 缺基线。图例全量渲染（"某条没出现"本身是信息）。

### 措辞守卫

扫描"证明 / 完全准确 / 无 p 值的显著优于 / 可外推 / 无系统偏差 / 归因于"等表述。
命中 error 级 → 写 `report/compliance.json` + 页面红色横幅；`report.strict_text=true`
时才抛异常。**否定句里的告诫不算违规**（"不得宣称模型可安全外推"是正确的，不能判成越界）。

### 图件完整性（`figures/figure_qc.json`）

| 检查 | 判据 |
|---|---|
| Q1 双 y 轴 | 两个坐标轴位置完全重合（twinx/twiny）→ 违规 |
| Q2 截断纵轴 | 柱状图的 y 下界 > 0 且数据下界更低，且未声明 `_sml_zero_declared` → 违规 |
| Q3 色标 | `jet / rainbow / gist_rainbow / gist_ncar / hsv` → 违规 |
| Q4 箱线图 | 有箱体但该轴无散点 → 违规 |
| Q5 轴标签 / 误差线 | 数值轴无标签；或 F8 无 ErrorbarContainer → 违规 |

`selfcheck.py` 在 smoke run 上断言该文件为空。注意 Q2 只针对柱状图：箱线图与散点图
按数据自动缩放是正常做法，不在此列。

### HTML 报告（`report/report.html`）

- 单文件、内联 CSS、**零外链零 JS**：断网、离线、审稿系统里都能原样打开。
- 图引用 `../figures/*.png` 原图，不重采样、不 base64——页面图与投稿图必须是同一字节。
- 每个数字带 `data-raw`（全精度原值）与悬停提示（来源文件 + 字段）；要复算请回 CSV。
- 三档断点：≥1100px 双栏（目录 + 正文）、760–1100px 单栏 + 表格横向滚动 + 首列吸附、
  <760px 隐藏目录。`@media print` 按 A4 排版，表头每页重复，图表不跨页断开。
- 表 T2 的 `†` 与 `metric_basis` 必须与性能一起读；页面在表注里直接写明，不靠读者自己发现。
